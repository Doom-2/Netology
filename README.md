# 🏎️ Симулятор гонок на C++

> **Учебный проект с использованием объектно-ориентированного программирования**
>
> Здесь на одной трассе могут встретиться верблюды, кентавр, волшебные ботинки, ковёр-самолёт и даже орёл. Выбирайте тип соревнования — наземный или воздушный, задавайте длину дистанции и собирайте собственный состав участников.

---

## ⚙️ Архитектура проекта

В основе проекта лежит **объектно-ориентированный подход**. Абстрактный класс `Vehicle` задаёт общий интерфейс для всех транспортных средств, а наземные и воздушные классы расширяют его.

Конкретные модели (`Camel`, `FastCamel`, `Centaur`, `SuperBoots`, `MagicCarpet`, `Eagle` и `Broom`) реализуют собственные правила расчёта времени.

**Наследование и полиморфизм** позволяют классу `Race` работать с разными участниками через единый интерфейс.

## 🏭 Паттерн «Фабрика»

Для создания объектов используется функция `createVehicle`. Она получает номер модели и возвращает умный указатель на объект нужного класса:

```cpp
std::unique_ptr<Vehicle> createVehicle(Race::VehicleModel vm) {
    switch (vm) {
    case Race::VehicleModel::CAMEL:
        return std::make_unique<Camel>();
    case Race::VehicleModel::FAST_CAMEL:
        return std::make_unique<FastCamel>();
    // Остальные модели транспорта
    default:
        throw std::invalid_argument("Invalid vehicle model");
    }
}
```

## 🔄 Полиморфизм и управление объектами

Расчёт времени выполняется полиморфным методом `calcRaceTime`. Каждый тип транспорта использует собственную реализацию, а виртуальный деструктор базового класса обеспечивает корректное освобождение объектов при работе через указатель `Vehicle`.

Класс `Race` отвечает за регистрацию участников, проверку совместимости транспорта с типом соревнования и контроль повторной регистрации. Для хранения зарегистрированных моделей используется `std::set`, а `std::unique_ptr` обеспечивает автоматическое управление памятью. Результаты заезда сохраняются в структуре `vehicleData` и обрабатываются с помощью `std::vector`.

**Пример объявления виртуального метода в базовом классе:**

```cpp
virtual double calcRaceTime(int dist) const = 0;
```

## 🏁 Логика соревнования

Пользовательский интерфейс построен на консольном меню: выбор типа гонки, ввод дистанции, регистрация транспортных средств и просмотр итоговой статистики.

**Для обработки некорректного ввода и других ошибок используются исключения.** Вспомогательные функции отвечают за проверку данных, очистку экрана и отображение информации.

## 🛠️ Сборка проекта

Проект использует **C++17** и собирается с помощью **CMake**.

Приложение разделено на исполняемый файл и динамическую библиотеку `RacingSimulatorDLL`, в которой находится основная логика гонки и классы транспортных средств. Такое разделение отделяет пользовательский интерфейс от логики симулятора.
