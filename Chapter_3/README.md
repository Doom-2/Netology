# Алгоритмы и структуры данных

- [1. Введение в алгоритмическую сложность. Бинпоиск](./Lesson_1)
  В заданиях исследуется поиск границы в отсортированном массиве: бинарный алгоритм находит, сколько значений строго больше заданной точки отсчёта, не просматривая элементы по одному.

- [2. Динамическое программирование и «жадность»](./Lesson_2)
  На примере чисел Фибоначчи сравниваются два подхода: наивная рекурсия с подсчётом вызовов и последовательное заполнение таблицы уже найденных значений.

- [3. Сортировки](./Lesson_3)
  Реализована быстрая сортировка: массив делится относительно опорного элемента, а затем каждая часть обрабатывается рекурсивно. Программа показывает исходные и упорядоченные массивы.

- [4. Динамический массив. Списки. Деки](./Lesson_4)
  Практика начинается с динамического массива, где отдельно учитываются его логический и фактический размеры. Свободные ячейки выводятся как подчёркивания, а память освобождается вручную.

- [5. Пирамиды и деревья поиска](./Lesson_5)
  Папка посвящена работе с иерархическими структурами данных и закрепляет представление о том, как организовывать быстрый доступ к элементам в деревьях и пирамидах.
